# CvGenerator

🎯 El Problema que Resolvemos
❌ Aplicar a empleos es frustrante:

📄 Mismo CV para todas las ofertas → Baja tasa de respuesta
⏰ Horas personalizando CVs manualmente → Pérdida de tiempo
🎯 No sabes qué keywords destacar → Los ATS te descartan
📊 Sin feedback sobre tu CV → No sabes por qué no te llaman
🔄 Proceso repetitivo y tedioso → Desmotivación

✅ CvGenerator: Tu Asistente Personal de Empleo
Genera CVs personalizados automáticamente para cada oferta en segundos, optimizados para ATS y diseñados para destacar exactamente lo que cada empresa busca.

✨ Features
🤖 Detección Inteligente de Ofertas
🔍 Escaneo Automático
   ├─ Detecta ofertas en LinkedIn, InfoJobs, Indeed, etc.
   ├─ Extrae requisitos, skills y keywords
   ├─ Analiza cultura y valores de la empresa
   └─ Identifica nivel de seniority y responsabilidades
¿Cómo funciona?

Navegas ofertas normalmente
La extensión detecta automáticamente nuevas ofertas
Analiza en tiempo real el contenido
Te muestra match score instantáneo


🎨 Generación de CV Personalizado
✨ IA Avanzada que:
   ├─ 📝 Reescribe tu experiencia destacando skills relevantes
   ├─ 🎯 Prioriza proyectos y logros según la oferta
   ├─ 🔑 Optimiza keywords para superar filtros ATS
   ├─ 📊 Ajusta formato según industria y empresa
   ├─ 🌍 Adapta idioma y tono profesional
   └─ ⚡ Genera múltiples versiones en segundos

📊 ATS Optimization Engine
🎯 Sistema que garantiza:
   ├─ 95%+ de compatibilidad con ATS
   ├─ Keywords exactos del job description
   ├─ Formato limpio sin elementos que confundan parsers
   ├─ Secciones estructuradas correctamente
   └─ Densidad de keywords optimizada
